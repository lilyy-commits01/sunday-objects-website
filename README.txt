SUNDAY OBJECTS WEBSITE

FILES
- index.html: the complete website. It works without installing anything.

PREVIEW
Open index.html in a web browser.

CUSTOMIZE PRODUCTS
Open index.html in a text editor. In the product catalog, duplicate an
<article class="product"> block and edit the product name, category, search
terms, description, and original-shop URL.

The sample product links use example.com. Replace them with real product URLs
before publishing.

DEPLOY WITH NETLIFY
1. Extract this ZIP file.
2. Visit https://app.netlify.com/drop
3. Drag the extracted folder containing index.html onto the page.
4. Netlify will publish the site and provide a public URL.
